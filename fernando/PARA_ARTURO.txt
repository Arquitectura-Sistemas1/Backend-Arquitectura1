Arturo, esto es lo que hay que hacer para integrar mis 2 endpoints:

1. Copiar schemas_item.py   -> app/schemas/item.py
2. Copiar services_item.py  -> app/services/item.py
3. Copiar endpoints_item.py -> app/api/endpoints/item.py
4. En app/api/router.py agregar:

   from app.api.endpoints.item import router as item_router
   router.include_router(item_router)

Con eso quedan disponibles:
GET /item/generos
GET /item/clasificaciones

=== PARTE 2: Comercial (agregar item a pedido) ===
1. Copiar schemas_comercial.py    -> app/schemas/comercial.py
2. Copiar services_comercial.py   -> app/services/comercial.py
3. Copiar endpoints_comercial.py  -> app/api/endpoints/comercial.py
4. En app/api/router.py agregar tambien:

   from app.api.endpoints.comercial import router as comercial_router
   router.include_router(comercial_router)

Con eso queda disponible:
POST /comercial/agregar-item-pedido
